### 平台基础模块（仅标准库，运行在 rag 环境）

| 模块 | 依赖 | Python |
| --- | --- | --- |

| `plugin_registry.py` | 标准库；`jsonschema` 可选 | 3.10+ |

### 平台 RAG 检索（rag 环境）

| 模块/能力 | 依赖 | 说明 |
| --- | --- | --- |
| `embedders.SentenceTransformerEmbedder` | `sentence-transformers`、`torch` | 首次运行会下载 bge 模型（约 100MB 级） |
| `embedders.OpenAICompatibleEmbedder` | 标准库 `urllib` | 只需 API Key；不要写进仓库 |
| `milvus_hybrid_index.py` | `pymilvus>=2.5` | BM25 Function 需要 Milvus 2.5+ |
| Milvus 服务 | Docker | 项目目标版主检索；无 Milvus 时回退关键词 |
| 重排（可选） | 外部 rerank API 或本地 cross-encoder | 不配置就不调用 |

### 多模态解析（docparse 环境，平台子进程调用）

| 能力 | 依赖 | 说明 |
| --- | --- | --- |
| 纯文本 PDF 原生抽取 | `PyMuPDF>=1.24`、`Pillow` | 不调用模型，速度快 |
| Office 解析 | `python-docx`、`python-pptx`、`openpyxl` | 原生结构解析 |
| 扫描件 OCR | Ollama + `longwayxu/xiaomi-ocr-0:bf16` | 项目目标版需要；纯文本接入不需要 |
| region 模式 | `paddlepaddle`、`paddlex[cv]`、`shapely` + PP-DocLayoutV3 | 约 1.1GB，CPU 可跑 |
| Web UI（原项目自带） | `fastapi`、`uvicorn`、`python-multipart`、`markdown` | 课程项目不需要 |

完整依赖见 `可选组件/docparse/requirements.txt` 与 `pyproject.toml`。

## 4. 密钥与敏感信息

原项目 `.env` 包含 SMTP、DeepSeek、DashScope 等真实配置，**没有复制**到本目录。
抽取代码中涉及密钥的位置：

| 位置 | 读取方式 | 建议 |
| --- | --- | --- |
| `OpenAICompatibleEmbedder(api_key=...)` | 构造参数 | 从环境变量读取，示例用占位符 |
| `docparse` 的 Ollama 地址 | docparse 自己的配置 | 默认 `127.0.0.1:11434` |
| 原项目 `.env.example` | 仅示例 | 保留占位符，不填真实值 |

课程项目提交前检查：

```bash
grep -RInE "(API_KEY|PASSWORD|SECRET|TOKEN)=" . --exclude-dir=.git
```

不要把 `.env`、日志、模型权重、`.pytest_cache` 打进 ZIP。
