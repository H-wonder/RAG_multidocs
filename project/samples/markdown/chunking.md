# 切块策略

## 按结构切

### 标题

标题进入章节路径，不进入正文。这样命中后能告诉用户“来自哪一节”。

### 表格

表格必须整块保留。按字符数切会把一行数据切成两半，检索结果无法阅读。

| 策略 | 优点 | 缺点 |
| --- | --- | --- |
| 固定长度 | 实现简单 | 容易切断句子和表格 |
| 按段落 | 保留语义 | 长段落仍会超预算 |
| 按结构 | 保留标题/表格/代码 | 依赖解析质量 |

## 按预算装箱

```python
def estimate_tokens(text: str) -> int:
    # 中文约 1 字 1 token，英文约 4.2 字 1 token
    return int(len(text) * 1.3)
```

块之间保留少量重叠，避免一句话被切成两半后两边都读不懂。
